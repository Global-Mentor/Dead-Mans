# Security

## Supported version

Dead Mans is under active development. Security fixes are made against the current `main` branch. There are no older supported releases yet.

## Reporting a vulnerability

Please send your report through a [private GitHub Security Advisory](https://github.com/Global-Mentor/Dead-Mans/security/advisories/new). Do not publish the details in GitHub Issues before the problem has been fixed.

Include the steps needed to reproduce the problem, its possible impact, and the affected part of the application. A small example or a sequence of requests can make the report much easier to verify.

## What to expect

I will try to acknowledge the report within a few days. After reviewing it, I will share whether the problem could be reproduced and how it is expected to be fixed.

Please allow a reasonable amount of time to prepare and release a fix before sharing the details publicly.

## Scope

Reports are welcome for the frontend, backend, OpenAPI contract, authentication, permissions, user data, file storage, and production configuration.

Problems that require physical access to the server or an already compromised developer computer are reviewed separately and usually are not considered application vulnerabilities.
