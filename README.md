# Dead-Mans

Dead-Mans — приложение для проведения игровых мероприятий на Twitch.

В нём можно подготовить игровое поле, собрать команды, провести раунды и викторину, использовать модификаторы и сохранить результаты игры. Зрители входят через Twitch, а изменения на игровом поле появляются у участников в реальном времени.

Проект состоит из React-интерфейса, ASP.NET Core API и PostgreSQL. Изображения хранятся в S3-совместимом хранилище.

## Локальный запуск

Понадобятся Docker, .NET 10 SDK и Node.js 22.

На Windows:

```text
setup-local.bat
dev-full.bat
```

После запуска приложение будет доступно по адресу <http://localhost:5180>.

Основной код находится в `frontend/` и `backend/`. Каталог `legacy-v1/` оставлен только как справочный материал.
