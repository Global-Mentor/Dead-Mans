# Миграция составных компонентов · 23 сентября 2026

Интерфейс использует общие контролы и составные компоненты на основе страницы заявки. Её внешний вид и поведение сохранены эталонными сравнениями. Ниже приведены карта замен и результаты проверок от 23 сентября 2026 года.

## Источники и замены

| Источник в заявке / прежняя реализация | Общий компонент и использование |
| --- | --- |
| `ApplicationSection` | Перенесён в существующий `FormSection`; прежний файл удалён. Заявка, формы каталога, списки модификаторов и секции очереди используют одну композицию |
| Заголовок секции заявки | `SectionHeader`; общий заголовок, разделитель и область действий |
| Группы создаваемых/подтверждённых команд | Существующий `DisclosureSection` переработан по эталону; управляемое раскрытие заявки сохранено, те же группы используются в истории, каталоге и администрировании модификаторов |
| Карточка команды заявки | `ItemCard`; обычное, доступное и выбранное состояние. Используется в очереди, модификаторах, истории, каталогах, викторине, настройке и игровых предпросмотрах |
| Подсветка выбора | `SelectionRow` использует ту же визуальную формулу `ItemCard`, отдельная полосатая тема удалена |
| Список участников заявки | `BulletList`; заявка и очередь команд |
| Состояние готовности команды | `SectionCard surface="muted"`; исходная геометрия заявки сохранена |
| Счётчики команд и мобильные переходы заявки | `SummaryMetrics` и `SectionNavigation`; извлечены без изменения исходного внешнего вида |
| Старые плитки сводки модификаторов и `PlayedCardResultMetric` | Существующий `Metric`: подпись/значение, описание, действие, доступный статус и подсказка |
| Плашки блокировки активации | Общие `StatusBadge`, `HelpTooltip` и `AppButton`; фиксированные 32px, локальные скругления и отдельные значки вопроса удалены |
| Рамки записей каталога, карточек истории и результатов | `RecordRow`/`ItemCard`; локальные рамки, градиенты и чередование фона удалены |
| Место в рейтинге | `RankBadge` на основе общего `StatusBadge`, дублирующий `getRankColor` удалён |
| Кнопки открытия боковых панелей | `PanelTrigger` задаёт размещение общей кнопки; отдельное округлое оформление удалено |

Новые варианты не добавлялись ради сохранения внешнего вида прежних вкладок. Специфические карточки доски, шапка и контекст над доской остаются самостоятельными компонентами согласно уточнению владельца. Бизнес-правила, данные, права, транспорт и расчёты не перерабатывались.

## Очистка

Удалены старый `ApplicationSection`, локальный `TeamGroupTitle`, `ModifierSectionHeading`, `SummaryLabel`, плитки `StatusMetric`/`TeamContextSummary`/`CardContextSummary`, `BlockedReasonPlaque`, `PlayedCardResultMetric`, `getRankColor`, устаревшие `alternate` и `data-history-tone`, локальные декоративные стили и неиспользуемые импорты. Типизация, линтер и Knip проверяют итоговую библиотеку.

## Исправления поведения

| Приоритет | Проблема | Исправление и проверка |
| --- | --- | --- |
| P1 | При refetch и перестановке модификаторов `keepDirtyValues` сохранял массив по индексам: введённое число могло перейти другой строке | Перенос только изменённых полей по идентичности группы/набора результатов; метаданные берутся из нового ответа. Интеграционный тест перестановки сначала воспроизвёл ошибку |
| P1 | После успешного изменения ролей и ошибки refetch интерфейс возвращал старые роли | Ответ mutation записывается в соответствующие записи всех страниц кэша перед обновлением. Регрессионный тест проверяет состояние ошибки запроса и сохранённую роль |
| P2 | Native select через callback слота или комбинацию старых/новых props получал `MenuItem` вместо `option`, а иногда терял label | Опции создаются внутри принадлежащего компоненту select-слота, после разрешения режима; два теста сначала воспроизвели ошибку |
| P2 | Подтверждение отмены итогов раунда оставалось открытым после внешнего закрытия редактора | Редактор и подтверждение живут в одной сессии, ограниченной `open` и ID раунда; тест закрытия/повторного открытия. Возврат числового поля к исходному значению не создаёт ложный dirty |
| P2 | Редактор категории сохранял черновик при смене редактируемой категории | Ключ по ID категории, стабильная исходная точка черновика; тест refetch того же объекта и перехода к другому |
| P2 | HTML-input слот вытеснял ограничения из `inputProps`; описание могло ссылаться не на реальный ID helper text | Согласованное объединение props и фактический ID подсказки; проверены min/max/step и accessible description |
| P2 | Боковая панель имела landmark, но не объявляла модальность | Именованный `dialog`, `aria-modal`, связь описания; Escape и возврат фокуса проверяются тестом |
| P2 | Контейнер доски переоформлял чужие кнопки через `& > button`; строки выбора копировали цвета/hover/focus | Общие `PanelTrigger` и `SelectionRow`, миграция доски, очереди, архивов и ревизий; оформление удалено из контейнера |
| P2 | Проверка границ пропускала namespace/re-export/dynamic imports и часть native controls | Явный список разрешённых основ MUI; проверка полиморфных контролов, алиасов и внешнего переоформления; отдельные тесты правил |
| P3 | Мобильные части таблицы использовали разные границы 899 и 899.95px | Одна граница `theme.breakpoints.down('md')`, явная табличная семантика при смене CSS display |
| P3 | Панели/диалоги не учитывали reduced motion; кнопки активации имели собственный размер 32px | Нулевые переходы панелей/диалогов при предпочтении пользователя, общие кнопки 44px, общий outlined-вариант иконок перестановки |

## Проверки

- Общий quality gate: 453 теста в 101 файле; форматирование, типы, линтер, локализации, 6 тестов архитектурных правил, coverage, Knip и production build прошли. Пороговые значения не ослаблялись.
- Тесты доски больше не привязаны к удалённому `.MuiPaper-root`; тесты модификаторов проверяют общую семантику/подсказки и действия вместо старых 28/32px и расположения самодельного значка вопроса. Проверки подтверждений, запретов и причин блокировки сохранены.
- Браузерный прогон: 116 сценариев прошли, один performance-сценарий запускается отдельно. После заключительных изменений карточек команд и reduced motion повторены затронутые группы: 65 сценариев прошли.

- Все 65 защищённых сравнений заявки и приглашений прошли с `maxDiffPixels: 0`; эталоны не перезаписывались.
- В браузерных тестах модификаторов добавлена проверка фактических скруглений всех поверхностей: общая тема, без старых 8/9/12px. В тесте короткого рейтинга ширина строки сравнивается с областью таблицы, учитывая нормальные отступы общей карточки. В тесте управления игрой для раскрывающихся секций проверяется доступный контракт триггера, а не удалённая внешняя рамка.
- Backend API, generated declarations и OpenAPI не менялись.

## Визуальные доказательства и ограничения

Эталонные изображения заявки находятся в `frontend/e2e/*-snapshots`. Браузерные тесты сохраняют снимки в `frontend/test-results`. Вручную осмотрены мобильные модификаторы, каталог, архив, предпросмотр результата и управление игрой, а также настольные модификаторы. Остальные маршруты проверены браузерными сценариями; ручной осмотр не следует считать полным перебором всех состояний.

Проверки используют Chrome на Windows и детерминированные API/WebSocket-фикстуры. Настоящие роли, игры, OAuth/Twitch и данные не изменялись. Физические устройства, реальная экранная клавиатура, screen reader, Firefox и Safari не проверялись. Coverage относится к настроенным критическим модулям: 86,49% statements, 88,43% branches, 89,68% functions, 86,40% lines; это не покрытие всего UI.
